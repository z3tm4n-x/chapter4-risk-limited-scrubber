# Risk-limited adaptive scrubber RTL

This repository is a clean Chapter 4 artifact for the dissertation work.

Goal: demonstrate that the risk-limited scrubbing method from Chapters 2-3 can be
implemented as an RTL controller that executes a discrete full-pass schedule,
corrects SEC-DED single-bit errors, reports detected uncorrectable states, falls
back to a conservative period when control updates are stale, and has measurable
hardware cost.

The RTL controller does not compute the radiation/risk model. It consumes an
external period index generated by the model-side schedule compiler.
